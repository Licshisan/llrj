# 流浪日记重制版 (LLRJ Remake)

> 基于 Cocos Creator 开发的生存 RPG 游戏

## 项目简介

《流浪日记》是一款文字类生存 RPG 游戏，玩家扮演一名流浪汉，在荒野、县城、山脉、城中村等多个场景中探索、战斗、生存，最终达成各种结局。

## 游戏特色

### 核心玩法
- **探索系统**：多地区探索（荒野、县城、山脉、城中村、郊外、市中心、山洞等）
- **战斗系统**：回合制战斗，包含暴击、格挡、反弹、嗜血等机制
- **生存管理**：管理饥饿、精力、健康、生命等生存指标
- **制作系统**：收集材料制作武器、装备、食物、药品
- **伙伴系统**：晓月、碧瑶、小兰三位伙伴，各有独特特性

### 天赋系统
- **特质**：开局抽取的角色特性，有正面和负面效果
- **天赋**：分普通、稀有、传说三个品质
- **局内特性**：游戏过程中达成条件解锁的能力
- **负面天赋**：增加游戏挑战性的负面效果

### 难度系统
| 难度 | 怪物倍率 | 说明 |
|------|----------|------|
| 普通 | 1.0x | 默认难度 |
| 试炼 | 1.5x | 较高挑战 |
| 残酷 | 2.0x | 高难度 |
| 炼狱 | 3.0x | 极限挑战 |

### 套餐系统
开局可选的特殊模式：
- **新手模式**：怪物血量减半，探索必得资源
- **旅游套餐**：初始果子+20、伤药+20、金钱+30
- **修罗模式**：怪物随天数增强，周末可解锁
- **鬼武者**：开局黑刀+红夹克
- **猎人套餐**：开局匕首+皮衣+食物
- 更多套餐...

## 核心机制

### 战斗机制
- **架势系统**：平衡架势、拼命架势、猥琐架势
- **特殊效果**：暴击、格挡、反弹、嗜血、闪避
- **状态效果**：暴躁（伤害+30%）、自信（敌人攻击-10%）、烟瘾

### 生存机制
- **饥饿**：低于0时探索/睡觉掉健康
- **精力**：探索消耗，睡觉恢复
- **健康**：影响生命上限
- **罪恶**：影响部分天赋效果和结局

### 伙伴系统
- **晓月**：增加攻击、恢复生命、战斗后额外奖励
- **碧瑶**：协同作战、暴击流血、治疗主角
- **小兰**：战斗恢复、探索增益

## 开发环境

- **引擎**：Cocos Creator
- **语言**：TypeScript
- **平台**：支持 Web、iOS、Android
