# 游戏结构
游戏难度：决定怪物属性倍率，不同难度有不同挑战。不同难度可能存在不同的剧情。
游戏套餐：开局前自主选择，可以解锁更多套餐。
开局特质：默认一个特质位，可以解锁更多特质和特质位。开局时自动抽取。特性有等级，通关完成成就等加强。
正面天赋：默认一个天赋位，可以解锁更多天赋和天赋位置。开局时自动抽取。游戏内亦有机会获得。天赋有三种品质，通关完成成就等获得。
藏品效果：默认携带10数量，通过打怪掉落，重开游戏生效，全局保留。
负面天赋：默认和天赋数量相同，默认全解锁。可以由其他天赋控制生效，和移除负面天赋。
局内特性：游戏原本特性内容，游戏进行时，达到某个条件自动解锁的内容和功能。
道具特性：游戏制作/升级。达到特性效果。新增宝物，一样的存在。
伙伴特性：解锁伙伴下，一定量好感度解锁的特性。
成就：原版成就/难度成就，游戏通过时结算，
最终评分：最终评分参与很多成就的判定。
挑战：在游戏难度和套餐的基础上（或者作为另一种套餐），对游戏难度的加强。
技能：另一种类似天赋或者特性的存在。
