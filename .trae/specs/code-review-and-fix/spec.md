# 流浪者日记 - 代码审查与修复计划

## 为什么

对项目进行全面的代码审查，修复语法错误和逻辑错误，完善代码使游戏能够合理运行。

## 项目结构概述

这是一个基于 Cocos Creator 3.x 开发的生存冒险游戏，核心代码位于 `assets/脚本` 目录下：

### 主要目录结构

* **管理器**：存档管理器、玩家管理器、设置管理器、钩子管理器

* **方法函数**：公共函数、属性计算、等级计算、动画效果、网络请求

* **场景脚本**：首页、主页、战斗、事件、存档、睡觉、进食、商店、剧情、伙伴、特性、住房、套餐、桥洞等

* **默认内容**：事件表、敌人表、食物表、天赋表、特性表、地区表、制作表、日记表、套餐表、伙伴特性表等

### 游戏核心系统

* **生存系统**：生命、精力、饥饿、健康、金钱

* **战斗系统**：PVE 和 PVP 战斗，含架势系统

* **天赋系统**：正面和负面天赋

* **事件系统**：随机事件和剧情事件

* **伙伴系统**：晓月、碧瑶、小兰三个伙伴及各自特性

* **存档系统**：本地存储存档

## 已修复的问题

### 1. 伙伴.ts 对话逻辑错误 ✅

**文件**: `assets/脚本/场景脚本/伙伴.ts`

**问题**: 对话选择逻辑错误，当固定对话用完后切换到随机对话时出现bug

**修复**: 重写了对话选择逻辑，使用明确的条件判断

```typescript
let dialog: string;
if (存档.伙伴.晓月聊天次数 < 固定对话.length) {
    dialog = 固定对话[存档.伙伴.晓月聊天次数];
} else {
    const index = Math.floor(Math.random() * 随机对话.length);
    dialog = 随机对话[index];
}
```

### 6. 开场.ts 随机抽取算法错误 ✅

**文件**: `assets/脚本/场景脚本/开场.ts`

**问题**: 使用`Array.from(new Set(shuffled))`去重会破坏权重系统

**修复**: 重写抽取算法，保持权重效果的同时避免重复选取

```typescript
// 使用Set记录已选中的物品索引，确保不重复选取同一物品
const selectedIndices = new Set<number>();
const result: T[] = [];
for (let i = 0; i < weightPool.length && result.length < count; i++) {
    if (!selectedIndices.has(i)) {
        selectedIndices.add(i);
        result.push(weightPool[i]);
    }
}
```
