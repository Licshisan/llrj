# 黑色森林体系方案

## 总方向

黑色森林是县城之后、山脉旁边的一条分支路线。它不做成全新的庞大系统，也不做成阴森恐怖或者高奇幻区域，而是沿用山脉的结构和资源逻辑：公共事件、山脉同类物品、近似魔法敌人、停留天数剧情、日记补叙、伙伴加入。

黑色森林的时代感要贴近当前游戏：主角是现代底层流浪状态，县城、省城、桥洞、打工、捡破烂、路边摊、便宜食物这些现实元素仍然存在。黑色森林的魔法感不是古典奇幻，而是“现代县城边缘的怪地方”：废弃林场、防火宣传牌、护林站、老式广播、被风吹歪的路牌、偷木头的人、套着迷信说法的真实危险，以及一些和山脉近似的魔法怪物。

```ts
const 黑色森林定位 = {
  地区名: "黑色森林",
  结构参考: "山脉",
  物品来源: "沿用山脉公共掉落和公共事件物品",
  事件来源: "使用公共事件，并补少量黑色森林专属事件",
  敌人风格: "和山脉近似的魔法怪物，但包装成县城边缘林场怪谈",
  剧情重点: "新增伙伴 + 林场旧事 + 离开县城后的另一种同行",
  不做内容: [
    "不单独设计一整套黑森林物品体系",
    "不做高奇幻世界观",
    "不做过度阴森恐怖",
    "不增加太多门派、组织、隐藏设定"
  ]
};
```

```ts
const 路线对照 = {

    战斗: "山脉野兽、山脉魔法敌人、山岭巨人等"
  },
  黑色森林: {
    核心: "新伙伴林小满剧情",
    氛围: "县城边缘废弃林场、护林站、现代怪谈、轻魔法",
    主要物品: "和山脉相同，不新增复杂物品体系",
    战斗: "黑色森林版山脉敌人，能力近似但文本和剧情不同"

```

黑色森林不应该抢走山脉的完整度，而是补一个“同样能遇到伙伴，但性格和剧情不同”的路线。玩家从县城离开时可以选择：

```ts
const 离开县城分支 = {
  进入山脉: "走大路，进入山脉，触发晓月线",
  进入黑色森林: "走旧林场路，进入黑色森林，触发林小满线"
};
```

## 新伙伴：林小满

林小满要性格鲜明，不能只是“安静懂森林”的工具人。她应该和晓月明显不同。

晓月是外放、能闹、贪吃、情绪直接。林小满则是嘴硬、爱记账、很现实、会吐槽，但是遇到危险会先把主角往后拽。她不是神秘少女，而是县城边缘长大的穷孩子，熟悉林场、护林站、废品站和偷木头的人。

```ts
const 林小满 = {
  名称: "林小满",
  身份: "住在黑色森林边缘的女孩，平时靠采野菜、捡废铁、给护林站跑腿换饭",
  年龄感: "比晓月更早熟，像是被生活逼着会算账的人",
  性格: [
    "嘴硬",
    "抠门",
    "爱记账",
    "遇事先算损失",
    "表面嫌弃主角，实际会偷偷帮忙",
    "相信一些林场老规矩，但不会装神秘"
  ],
  口头禅: [
    "先说好，这个要算钱。",
    "你别动，我不想明天还得挖你。",
    "这不是迷信，这是经验，经验懂不懂？",
    "你要是把命丢这儿，我可不负责背你。"
  ],
  伙伴定位: "野外探索、减少损耗、提升山脉同类物品收益",
  关系主题: "从互相嫌弃到真正搭伙"
};
```

## 事件设计

黑色森林使用公共事件，不需要完全独立。专属事件只补“地区味道”和“林小满关系”。

```ts
const 黑色森林事件设计 = {
  使用公共事件: [
    "探索获得山脉同类物品",
    "挖掘",
    "捡拾",
    "随机战斗",
    "休息或消耗精力类事件"
  ],
  专属事件: [
    {
      名称: "旧罚款牌",
      作用: "轻度损失或获得木材",
      选项: {
        绕开: "损失少量精力",

    {
      名称: "废弃护林站",

      条件: "黑色森林停留天数 >= 7",

    },
    {
      名称: "林小满记账",

```

## 物品策略
