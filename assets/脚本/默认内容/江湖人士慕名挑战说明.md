# 江湖人士慕名挑战系统说明

## 一、系统概述

"江湖人士慕名挑战"是游戏中的一个隐藏剧情系统，玩家通过积累江湖名气来触发与各大门派高手的对决。

## 二、核心概念

### 江湖名气 (Jianghu Reputation)
- **存储位置**: `存档.jh.jhmq`
- **初始值**: 0
- **获取方式**: 击败江湖人士 +1 名气
- **显示位置**: 个人面板显示 "江湖名气: X"

## 四、随机遭遇

### 江湖人士随机遭遇

**遭遇概率**:
- 省城: 极低 (第30天前2%, 第30天后1%)
- 山脉: 18%
- 其他地区: 30%

**敌人属性计算**:
```
生命值 = parseInt(15 * day^1.2) * 100
攻击力 = 生命值 / 50
防御力 = 生命值 / 50
```
- 真实二阶难度: 生命值 * 1.4

**遭遇特点**:
- 省城: 敌人通常没有防御武功
- 敌人名字随机生成 (姓+名组合)
- 门派从蓬莱阁/玄武门/归云庄中随机

## 五、战斗奖励

### 胜利奖励
1. **江湖名气**: +1
2. **战利品**: 根据随机概率掉落物品
3. **养身道具**:
   - 50%概率: 养身散 *1
   - 20%概率: 养身丹 *1
   - 拾荒者特性: 保底获得

### 失败惩罚
- 自定义败北语(门派特有)

- `获取江湖名气()`: 获取当前江湖名气
- `增加江湖名气(数值)`: 增加江湖名气
- `获取随机江湖人士()`: 生成随机江湖人士
- `构建蓬莱阁敌人123()`: 构建蓬莱阁三个剧情敌人
- `构建玄武门敌人123()`: 构建玄武门三个剧情敌人
- `构建随机江湖敌人(难度系数)`: 构建随机江湖敌人
- `构建江湖人士(名字, 门派, 攻击武功, 防御武功, 生命值, 攻击力)`: 从江湖人士构建完整敌人

## 八、注意事项

1. 真实一阶和真实二阶剧情的敌人ID不冲突
2. 江湖名气不会因为失败而减少
3. 剧情只能触发一次，失败后无法重试
4. 随机遭遇不受剧情状态影响
5. 真实二阶难度下敌人属性会增强40%
