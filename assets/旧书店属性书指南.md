## 四、学习机制

### 使用流程
1. 购买书籍 → 存入物品栏
2. 点击使用 → 消耗精力和饱食度
3. 增加学习进度 → 逐步获得属性加成
4. 进度达上限 → 书籍效果完全生效

### 属性计算公式
```
实际加成 = 基础加成 ± 浮动范围
```

## 五、书籍效果对比

### 性价比推荐
| 优先级 | 书籍 | 理由 |
|--------|------|------|
| ⭐⭐⭐ | 《健身营养学》 | 同时提升生命和饱食上限，性价比最高 |
| ⭐⭐ | 《健身指南》 | HP加成最高，消耗较低 |
| ⭐⭐ | 《搏击技巧基础教程》 | 唯一攻击书，输出必备 |
| ⭐ | 《警用防身术》 | 防御最高，但价格和消耗也最高 |

### 核心作用
- **生命类**: 提升生存能力，增加容错空间
- **防御类**: 减少受到的伤害，适合坦克打法
- **攻击类**: 提升输出能力，加快战斗效率
