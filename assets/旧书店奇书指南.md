## 三、书籍质量体系

### 质量等级

旧书店的书籍存在4种质量等级，影响价格和属性效果：

| 质量等级 | 价格倍率 | 属性倍率 | 基础概率 | 颜色 |
|----------|----------|----------|----------|------|
| **轻微破损**（lv1） | 0.75 | 0.75 | 30% | 白色 |
| **陈旧**（lv2） | 0.9 | 0.9 | 30% | 白色 |
| **完好**（lv3） | 0.9 | 1.0 | 0%（需解锁） | 绿色 |

### 质量对属性的影响

```
实际属性 = 基础属性 × 属性倍率
实际价格 = 基础价格 × 价格倍率
```

**示例**：《猛男速成班》（基础HP+80，价格400元）
- 轻微破损：HP+60，价格300元
- 陈旧：HP+72，价格360元
- 完好：HP+80，价格360元

### "完好"书籍解锁条件

「完好」书籍默认概率为0，需通过以下方式解锁：

| 解锁方式 | 增加概率 |
|----------|----------|
| 拥有Support6赞助特权 | +10% |
| 达成成就「资格(良好)」 | +5% |
| 达成成就「资格(良好·平行)」 | +1% |

## 五、学习机制

### 使用流程
1. 购买书籍 → 存入物品栏
2. 点击使用 → 消耗精力和饱食度
3. 增加学习进度 → 逐步获得属性加成
4. 进度达上限 → 书籍效果完全生效

### 属性计算公式
```
实际加成 = 基础加成 × 属性倍率 ± 浮动范围
```

## 六、旧书店触发概率

### 触发条件
旧书店是随机探索事件（事件ID：40002），需满足：
- 已解锁旧书店（达成成就「一战之力·平行」或拥有Support2天赋）
- 在省城或城中村区域探索

### 触发概率

| 区域 | 基础概率 | 保底机制 |
|------|----------|----------|
| **省城** | 3.33%（1/30） | 无 |
| **城中村** | 20%（1/5） | 探索20次必触发一次 |

### 概率提升方式

| 方式 | 效果 |
|------|------|
| 达成成就「横扫·平行」 | 旧书店出现多个商品的概率提高10% |
| 赞助特权（友情赞助） | 提前解锁旧书店，商品数量+1 |

## 七、书籍效果对比

### 性价比推荐
| 优先级 | 书籍 | 理由 |
|--------|------|------|
| ⭐⭐⭐ | 《科学干饭指南》 | 同时提升生命和饱食上限，性价比最高 |
| ⭐⭐ | 《猛男速成班》 | HP加成最高，消耗较低 |
| ⭐⭐ | 《格斗入门：点到为止》 | 唯一攻击书，输出必备 |
| ⭐ | 《硬核抗揍术》 | 防御最高，但价格和消耗也最高 |

### 核心作用
- **生命类**: 提升生存能力，增加容错空间
- **防御类**: 减少受到的伤害，适合坦克打法
- **攻击类**: 提升输出能力，加快战斗效率

## 八、获取途径

旧书店是随机探索事件，解锁条件：
- 达成成就「一战之力·平行」或拥有Support2天赋
- 在省城探索时有概率触发（3.33%）
- 在城中村探索时概率更高（20%）
