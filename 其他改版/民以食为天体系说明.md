# 民以食为天系统说明

## 一、系统概述

"民以食为天"是游戏中的一个可选挑战模式，代号 `民以食为天`，通过 `存档.challengeModelList` 中的 `swt` 标志激活。

该系统为游戏引入了完整的**体质-营养体系**，完全重构了饮食和属性增长的逻辑，使游戏从"无脑吃果子"转变为需要**合理搭配饮食、管理营养值**的策略性玩法。

## 二、核心数据

### 体质 (Strength)

| 属性 | 说明 |
|------|------|
| 存储位置 | `存档.strength` |
| 初始值 | 0 |
| 作用 | 决定精力上限、营养值上限、战斗力等 |
| 获取方式 | 通过营养吸收（消耗营养值）提升 |
| 精力转换 | `精力上限 = 体质 * 10` |
| 营养上限 | `营养值上限 = 5 + 体质 * 5` |

### 营养值 (YYZ)

| 属性 | 说明 |
|------|------|
| 存储位置 | `存档.yyz` |
| 初始值 | 0 |
| 作用 | 升级体质所需的资源 |
| 消耗方式 | 日常代谢消耗、营养吸收消耗 |
| 上限 | 受体质值限制（`5 + 体质 * 5`） |

### 气血 (QX)

| 属性 | 说明 |
|------|------|
| 存储位置 | `存档.qx` |
| 作用 | 战斗中的额外属性，类似生命值加成 |
| 获取方式 | 吃补品食物、日常代谢恢复 |

## 三、日常系统

### 民以食为天专属增益计时器

#### 1. 营养吸收 (ID: 3)

| 属性 | 值 |
|------|-----|
| 触发时间 | 每次睡觉 |
| 触发条件 | 开启民以食为天挑战 |
| 效果 | 消耗营养值，转化为体质和气血 |

**计算公式**:
```
升级体质所需营养 = 5 * 当前体质 + 10（每级递增）
体质提升 = 当前营养值 / 升级所需营养
```

**示例**:
- 体质 0 → 1 需要 10 点营养
- 体质 1 → 2 需要 15 点营养
- 体质 2 → 3 需要 20 点营养
- 以此类推...

#### 2. 日常代谢 (ID: 4)

| 属性 | 值 |
|------|-----|
| 触发时间 | 每次睡觉 |
| 触发条件 | 开启民以食为天挑战 |
| 效果 | 消耗饱食度和营养值，恢复气血 |

**计算公式**:
```
饱食度消耗 = 体质 * 20
营养值消耗 = floor(体质 / 5)
气血恢复 = 营养值消耗 * 2
```

**特殊情况**:
- 如果营养值不足：体质-1，营养值归零

#### 3. 气血恢复 (ID: 5)

| 属性 | 值 |
|------|-----|
| 触发时间 | 每次睡觉 |
| 触发条件 | 开启民以食为天挑战 |
| 效果 | 消耗营养值恢复气血 |

**计算公式**:
```
恢复量 = 营养值 / 2
```

## 四、食物系统变化

### 普通模式 vs 民以食为天模式

| 属性 | 普通模式 | 民以食为天模式 |
|------|---------|---------------|
| 饱食度恢复 | 直接恢复饱食度 | 恢复饱食度+营养值 |
| 生命值加成 | 直接增加最大生命 | 增加营养值和气血 |
| 香烟效果 | 恢复精力、饥饿、生命 | 恢复精力、生命，不恢复饱食度 |

### 食物数据结构

```typescript
interface 食物模型 {
    id: number,
    code: string,
    name: string,
    yyz: number,        // 营养值增量
    qx: number,         // 气血增量
    hunger: number,     // 饱食度增量
    price: number,      // 价格
}
```

### 典型食物（高级补品）

| 食物名称 | 饱食度 | 营养值 | 气血 | 价格 |
|---------|--------|--------|------|------|
| 糯米鸡 | 500 | 80 | 20 | 550 |
| 鹿茸人参汤 | 500 | 80 | 500 | 800 |

### 食物效果逻辑

**普通食物 (buildFoodModel)**:
- 增加饱食度
- 增加营养值
- 可能触发额外效果

**补品食物 (buildFoodBpModel)**:
- 在民以食为天模式下：
  - 增加饱食度 + 营养值 + 气血
- 在普通模式下：
  - 增加饱食度 + 最大生命值

2. 日常代谢（消耗饱食度和营养恢复气血）
3. 气血恢复（消耗营养恢复气血）

## 九、注意事项

1. **营养值不会溢出**：增加营养值时自动限制在上限内
2. **体质只增不减**：通过营养吸收提升，不会因营养不足而下降（日常代谢的特殊情况除外）
3. **中年大叔剧情独立**：即使未完成也不会影响游戏主流程
4. **挑战模式锁定**：一旦选择民以食为天，该局游戏将全程生效
5. **香烟效果改变**：在民以食为天模式下不恢复饱食度
